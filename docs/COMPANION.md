# 手机伴侣（Phone companion）

在手机上回答三个问题：**自动搜索现在在不在跑、找没找到、花了多少**；外加一件事：**把想法记下来发给这台电脑**。

它是一个装到主屏幕的网页应用，不是 App Store 里的原生应用（原因见最后一节）。默认关闭。

## 怎么用

1. 电脑上：Helm → 设置 → 手机伴侣 → 打开。会列出一两个地址，比如 `http://你的电脑名.local:4378`。
2. iPhone 上（和电脑同一个 Wi-Fi）：用 Safari 打开那个地址 → 分享 → 添加到主屏幕。
3. 电脑上点「生成配对码」，把 6 位数字填到手机上。之后不用再配对。

不在家时连不上电脑：「现在」页显示上次看到的内容；写的想法先存在手机里，下次连上自动发出去。想在外面也能看，用 Tailscale 之类的 VPN 让手机能访问电脑的 4378 端口即可，Helm 这边不用改。

## 手机上有什么

**现在**
- 一句话结论：正在找（第几轮）/ 找到 N 个候选 / 这次没找到（以及为什么停）/ 出错停下了。
- 用量：合计花费和上限、输入 / 输出 / 缓存 token、试过的想法数、想法检验次数、开发期版本数、看过几次验证期、用时。连续模式下是所有轮次合计。
- 这一轮的想法清单和每个的结论。
- 在跑的模拟实盘：前向收益、同期基准、交易日数、上次运行是否失败。

**想法**
- 写一段话，发给电脑。它进电脑上的收件箱（首页「手机发来的想法」），你点「用这个想法」才会填进想法框，再由你交给团队。
- 发过的想法和各自的状态：在收件箱 / 已交给团队 / 已忽略 / 等着发。

token 数从这个功能上线后开始记；之前的几轮只有花费。

## 安全边界

这是 Helm 唯一会监听局域网的地方，所以做得很窄：

| | |
|---|---|
| 默认 | 关。打开要在设置里点，并确认一次 |
| 服务 | 另一个端口（4378）、另一个 HTTP 服务。主服务仍然只监听 127.0.0.1 |
| 能做的事 | 配对；读摘要；读收件箱；往收件箱写一条想法。只有这 4 个接口，外加 5 个静态文件 |
| 做不到的事 | 开对话、派 agent、跑回测、读写代码、读密钥、碰模拟实盘、改设置。这些接口在伴侣端口上不存在；主页面的令牌在这里也不认 |
| 手机发来的想法 | 只进收件箱，不会自己开工。否则拿到令牌的人就能远程花你的用量 |
| 配对 | 电脑上生成 6 位配对码：10 分钟有效、只能用一次、错 5 次作废。换到的令牌是 256 位随机数，存在 `data/companion.json`（0600） |
| 限速 | 同一个地址 10 分钟内错 20 次（配对码或令牌），拒绝 10 分钟 |
| 摘要里有什么 | 数字、想法标题、项目名、模拟实盘名。没有代码、对话内容、文件路径、密钥 |
| 收件箱 | 一条最多 2000 字；没处理的满 50 条就不再收 |
| 撤销 | 「断开所有手机」作废令牌；「关闭手机伴侣」停止监听 |

**没有加密。** 连接是普通 HTTP：能看到你网络流量的人（比如同一个公共 Wi-Fi 上的人）能读到令牌和摘要，也能往收件箱里写东西。只在你信任的网络上打开，或者走 VPN。

## 接口（给以后做原生应用用）

都在伴侣端口上。除了配对，都要 `Authorization: Bearer <token>`。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/pair` | `{ code }` → `{ token }` |
| GET | `/api/summary` | 见 `buildSummary`（`lib/companion.mjs`）：`{ at, host, search, paper, inbox }` |
| GET | `/api/ideas` | 最近 50 条：`{ ideas: [{ id, at, text, status }] }` |
| POST | `/api/ideas` | `{ text }` → `{ idea }` |

主服务（只在本机）上对应的接口：`GET/POST /api/companion`（状态；`action` = enable / disable / pair / reset）、`GET/POST /api/inbox`（列表；`{ id, action: used | dismissed }`）。

端口可以用环境变量 `HELM_COMPANION_PORT` 改。

## 为什么不是原生 iOS 应用

- 原生应用要 Xcode 编译、要 Apple 开发者账号签名（免费账号装的应用 7 天过期），每次改动都要重新装。
- 这个应用要做的事（看几个数字、写一段话）网页应用都能做，装到主屏幕后全屏运行、有自己的图标。
- 做不到的只有一件：**推送通知**（「找到了」时主动提醒你）。这需要原生应用或一个中转服务。

上面的接口已经是完整的后端。以后要做原生应用（SwiftUI + 通知），只需要写客户端。
