# Code of Conduct

Helm is a small personal research project that is shared so others can read, discuss and contribute. Anyone taking part is expected to:

- Argue about the code, the statistics and the evidence, not about people. Say when you disagree and why.
- Be honest about uncertainty. A backtest or a paper-trading curve is not proof that a strategy works, and posting one as proof misleads other people.
- Keep private material out of issues, pull requests and discussions: API keys, Alpaca credentials, account details, and the contents of `data/` or `projects/`.
- Do not harass, threaten or demean anyone, and do not publish personal information about anyone without their consent.
- Accept that the maintainer decides what is merged. A research rule that is inconvenient may still be the right rule.

This applies to the repository, its issues, pull requests and any discussion space the maintainer runs.

## Reporting

Report concerns privately through the repository's **Security** tab (**Report a vulnerability**), noting that it is a conduct report, since GitHub has no separate private channel for this. The maintainer will read each report and reply privately. The maintainer decides what follows, which may include removing content or limiting someone's participation in project spaces.

Security vulnerabilities are not conduct reports. Use the process in `SECURITY.md`.
